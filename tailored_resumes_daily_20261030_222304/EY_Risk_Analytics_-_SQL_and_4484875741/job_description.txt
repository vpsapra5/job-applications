Expert-level proficiency in SQL with hands-on experience in:   Complex Joins  Window Functions  Common Table Expressions (CTEs)  Stored Procedures  Query Optimization  Execution Plan Analysis  Indexing Strategies  Partitioning  Performance Tuning   Strong experience designing and developing ETL/ELT pipelines using tools such as:   Azure Data Factory (ADF)  SSIS  Informatica  Talend  DataStage  Spark/PySpark  Equivalent enterprise ETL platforms   Hands-on experience building and maintaining:   Data Ingestion Pipelines  Incremental Load Frameworks  Batch Processing Solutions  Data Transformation Pipelines  Data Integration Workflows   Strong understanding of Data Warehouse concepts including:   Star Schema  Snowflake Schema  Fact & Dimension Tables  Slowly Changing Dimensions (SCD)  Change Data Capture (CDC)  Data Modeling Techniques   Experience working with large-scale relational and analytical databases such as:   SQL Server  Oracle  PostgreSQL  Snowflake  Azure Synapse  Teradata   Experience building and maintaining:   Data ingestion pipelines  Data transformation workflows  Batch processing jobs  Data integration solutions   Strong understanding of data extraction, transformation, and loading processes across multiple systems.  Experience working with relational databases such as SQL Server, Oracle, PostgreSQL, Snowflake, or equivalent.  Ability to analyze business requirements and translate them into efficient ETL solutions.  Experience investigating and resolving data issues using SQL and ETL troubleshooting techniques.
